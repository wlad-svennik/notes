## 1. CombNF as stated

`CombTheory.lean`, the first 165 lines.

**Language `ℒᴄ`.** Application `f · x` (binary), a unary function symbol `K`, three constants `B`, `R`, `q`, and equality. `K` is a function symbol, not an object: `K(x)` is the constant function with value `x`.

**Axioms.**

| Axiom | Statement |
|---|---|
| equality | the axioms of equality for `ℒᴄ` |
| `kAx` | `K(x) · y = x` |
| `bAx` | `B · x · y · z = x · K(z) · (y · z)` |
| `qTrue` | if `x · y = y` then `q · x · y = B` |
| `qFalse` | `x · y = y` or `q · x · y = R` |
| `extensionality` | if `f · x = g · x` for all `x` then `f = g` |
| `nontrivial` | `B ≠ R` |

Choices made in the statement, to compare with yours:

- This is C₀ as in the dictionary of our chat of 16 November: `K(a)` is `λy.a`, `B` is `λa.λb.λc. a (λy.c) (b c)`, `q` is `λf.λx.(f x ≐ x)`, `R` is `⊥`, and the true value is `B`.
- Extensionality is an axiom with a quantifier. It is not written with a witness symbol.
- Nothing is assumed about `R` except `B ≠ R` and that it is the value of `q` at a non-fixed point.
- There is no stratification condition anywhere in the axioms. Stratification appears only in §2, as the condition under which a λ-term has a combinatory translation.

## 2. CombNF interprets FunctionNF (`CombFn.lean`)

Fix a model `M` of `𝗖𝗡𝗙`. Read `⊤` as `B`, `⊥` as `R`, and `s ≐ t` as `q · K(s) · t` (`EqC`). Then `(a ≐ a) = B` because `K(a) · a = a`, and `(a ≐ b) = R` for `a ≠ b` because `K(a) · b = a ≠ b` (`eqC_self`, `eqC_ne`). What remains is the abstraction axiom of FunctionNF for every stratified λ-term.

| Step | Statement | Lean |
|---|---|---|
| identity | `I = B (B B B) B` satisfies `I · z = z` | `i_app` |
| normal terms | a normal term is an application tree whose leaves are `K^m(a)`, `a` a variable or a constant | `NT`, `nval` |
| `K` goes to the leaves | `K(u v) = B K(u) K(v)`, by extensionality | `kpush`, `nval_kpush` |
| abstraction | `abs j T` with `abs j T · K^j(x) = T`, when every occurrence of `x` in `T` is under the right number of `K`s | `abs`, `Good`, `abs_spec` |
| levels | in a normal term `K` raises the level by one; a stratified normal term with `x` at `j` levels below it is `Good j` | `NLev`, `nlev_good` |
| translation | `tr` sends `λx.t` to `abs 0 (tr t)` and `s ≐ t` to `q · K(tr s) · tr t`; it preserves levels | `tr`, `nlev_tr` |
| values | the value of `tr t` is a value of `t` | `den_tr` |

The definition of abstraction is

- `abs j (K^j(x)) = I`,
- `abs j (K^m(a)) = K^(m+1)(a)` for another variable or a constant `a`,
- `abs j (U V) = B (abs (j+1) U) (abs j V)`.

It works because `B F G z = F K(z) (G z)`: in `U V` the function `U` is one level above `V`, so the variable occurs in `U` under one more `K`, and `B` supplies exactly that `K`. No renaming of `K(x)` to a fresh variable is needed.

`combInterpretsFn` follows: the translation sends `f · x = y` to itself, `(a ≐ b) = y` to `y = q · K(a) · b`, `y = ⊤` to `y = B` and `y = ⊥` to `y = R`.

## 3. NF interprets CombNF (`NFInterpretsComb.lean`)

Fix a model `V` of `𝗡𝗙`, with the application `AppR` of `NFFn.lean`. Each symbol is an object given by its graph. It exists by comprehension applied to the graph and the bijection between the universe and the set of functions (`app_of_graph`), and it is unique by extensionality.

| Symbol | Definition | Lean |
|---|---|---|
| `K(a)` | the `k` with `k · y = a` for all `y` | `KR`, `exists_k`, `k_unique` |
| `B` | the value of the λ-term `λa.λb.λc. a (λy.c) (b c)`, which is stratified at level 3 | `termB`, `IsB`, `b_spec` |
| `R` | the empty set; the universal set if `B` is the empty set | `IsR`, `b_ne_r` |
| `q` | `q · f` is the `g` with `g · x = B` if `f · x = x` and `g · x = R` otherwise | `QG`, `QF`, `IsQ`, `q_spec` |

- `B` is obtained from `denV_exists` of `NFInterpretsFn.lean`, since its λ-term contains no `⊤`, `⊥` or `≐`.
- `q` is not obtained from the λ-term `λf.λx.(f x ≐ x)`, because the truth values of the interpretation of FunctionNF in NF are the universal set and the empty set, not `B` and `R`. It is built directly, by two applications of `app_of_graph`.
- The case distinction in `R` avoids having to prove that `B` is not the empty set.

In a model `V` of `𝗡𝗙` the interpreted structure satisfies the six properties of `CNF.models_of` (`combModel_models`), and `nfInterpretsComb` follows by the completeness theorem of the library.

## 4. What the consistency statements do and do not say

`CombAll.lean` has `consistent_comb_iff_consistent_nf` and `consistent_comb : Consistent 𝗖𝗡𝗙`. As for FunctionNF, `consistent_comb` is a theorem because Lean proves `Consistent 𝗡𝗙𝗨𝗜` outright; it shows that the interpretations are not vacuous, and it makes the equivalence true for a trivial reason. What carries the information is the interpretations of §0.

**Not established:**

- That CombNF and FunctionNF prove the same sentences under the two translations. `𝗖𝗡𝗙 ⊳ 𝗙𝗡𝗙` is direct; `𝗙𝗡𝗙 ⊳ 𝗖𝗡𝗙` goes through NF, because FunctionNF as stated has `⊤` as a constant with no axioms, where CombNF has `⊤ = B`.
- Anything over a weak base theory: all interpretations are proved through the completeness theorem.
