# Interpretability and equiconsistency of NF and related theories

This directory makes the submitted Lean proofs and eleven written expositions browsable on GitHub. The source files retain the original text. For the complete build layout, pinned dependencies and checker outputs, use the [original project archive](../nf-interp.zip). The [index for all seven theories](../SET-THEORY-PROOFS.md) maps NF, FunctionNF, CombNF, M, MAC, M+H and NFU + Infinity to their formal declarations. [FILES.md](FILES.md) records where the individual files came from in the original project.

Start with [MutualInterpretability.lean](MutualInterpretability.lean) for NF and NFU + Infinity, [CombAll.lean](CombAll.lean) for the combinator and function theories, [MacNFU.lean](MacNFU.lean) for M, or [MacChoiceAll.lean](MacChoiceAll.lean) for M+H and MAC.
